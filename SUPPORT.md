# Support

## Documentation

Most questions are answered in the [documentation](https://docs.fingerly.io):

- [Quick start](https://docs.fingerly.io/docs/quick-start)
- [SDK guides](https://docs.fingerly.io/docs/sdks)
- [Troubleshooting](https://docs.fingerly.io/docs/troubleshooting)
- [API reference](https://docs.fingerly.io/reference/overview)

## Questions and account help

Write to [support@fingerly.io](mailto:support@fingerly.io). Mention the SDK and version you use, and your platform or runtime. If you have one, include the request id from the response (an opaque id, safe to share).

Never send secret keys, webhook secrets or personal data. Redact them.

## Bugs and feature requests

Open an issue on the repository of the SDK or package concerned. The [organisation page](https://github.com/fingerly-io) lists every repository.

## Security vulnerabilities

Do not open a public issue. Follow the [security policy](SECURITY.md) and write to security@fingerly.io.
